# GitHub read contract
NewClient(baseURL,token string,httpClient *http.Client,maxBytes int64) *Client.
Client.Change(ctx,owner,repo string,number int) (Change,error) GET /repos/{owner}/{repo}/pulls/{number}. Change fields RepositoryID,SourceRepositoryID,HeadOID,TargetOID string. Require response id/repo IDs, head/base sha and reject mutable/missing revision; no assumption of fixed SHA length. HTTP errors, oversized body, context cancellation must return errors. Never return successful empty/unknown source identity.
TrustedCheck(Check, expectedProducer, expectedOID string) bool. Check fields Name,Producer,OID,Conclusion string. Only exact producer/revision success qualifies. Name alone insufficient.
CreateComment(ctx,owner,repo,number,body) and UpdateComment(ctx,owner,repo,id,body) write PR issue comments and return Comment{ID,Body,AuthorID} from the response; 401/403/404/410/422 are ErrRejected (definitely not written), other failures ambiguous. Non-2xx responses are *StatusError.
ReviewComments(ctx,owner,repo,number,maxPages) lists inline review comments with author and position. CreateReviewComments(ctx,owner,repo,number,commitID,[]NewReviewComment) posts them as one COMMENT review bound to commitID (side RIGHT or LEFT; a comment with StartLine > 0 spans StartLine..Line on the same side via start_line/start_side, used for multi-line suggestions); UpdateReviewComment edits one. Writes classify 401/403/404/410/422 as ErrRejected.
NewClientWithTokenSource(baseURL, TokenSource, httpClient, maxBytes) asks the token source on every request; a token-source error fails the request before it is sent. UserID(ctx, login) is GET /users/{login} with a validated, path-escaped login; BotLogin(slug) is slug+"[bot]".
GitHub App: ParsePrivateKey accepts exactly one unencrypted PEM RSA key (PKCS#1 or PKCS#8, >= 2048 bits) and never echoes key material. SignAppJWT signs RS256 with iat=now-60s, exp=now+9m, iss=app ID. App.Identity (GET /app, ID must equal AppID), App.Installation (GET /repos/{o}/{r}/installation) and App.InstallationToken (POST /app/installations/{id}/access_tokens, scoped to the given repositories, 201 with token and future expires_at) authenticate with the JWT, never follow redirects and never put the JWT or token in errors. InstallationTokenSource caches the token and refreshes it TokenRefreshMargin (5 minutes) before expiry; safe for concurrent use.
ValidLogin(login) matches ^[A-Za-z0-9][A-Za-z0-9-]{0,38}(\[bot\])?$. CollaboratorPermission(ctx,owner,repo,login) (Permission{Permission,RoleName,Login},error) is GET /repos/{owner}/{repo}/collaborators/{login}/permission with validated owner/repo and a ValidLogin, path-escaped login (invalid: error, no request). 404 returns Permission{}, nil. A 200 whose user.login differs (case-insensitive) or whose permission is empty is an error.
